Sinkronisasi Google Drive

Simpan file Excel utama di Google Drive. Sinkronkan untuk mengambil data terbaru; edit produk dari Admin akan memperbarui file Excel di Drive.

Client ID dan ID file Excel disimpan di database Supabase, sehingga otomatis tersedia di browser/perangkat lain saat Admin login. File .xlsx/.xls tetap privat. Google meminta izin membaca dan memperbarui file. Setiap edit produk akan memperbarui Excel di Drive dan database online.

Backup & Pemulihan

Backup otomatis sebelum upload, sinkronisasi Google Drive, dan edit produk. Lima backup terakhir disimpan di database.

Backup menyimpan data produk dan alamat foto. File foto tetap berada di Supabase Storage. Unduh JSON untuk menyimpan salinan di komputer. Pemulihan membuat katalog baru dan tidak menghapus backup sumber.
